# molecular-cloning · 0.1.0

Molecular cloning, primer design, codon optimization, virtual construct assembly, and Sanger ABIF verification plugin (`toolPrefix: mc`, agent `MolecularCloning`) in a locked offline Python environment (`plugin:mc`: Python 3.13 + `pandas/numpy/scipy/scikit-learn/matplotlib-base`, 100% pure MIT + `conda-forge` with zero GPL dependencies).

## Tools (`mc_*`, 4 tools in `cloning-workflow`)

- **`mc_design_primers`**: Design primer pairs for `PCR`, `qPCR`, `Gibson`, `GoldenGate`, and `SiteDirectedMutagenesis` (Q5 back-to-back & QuikChange overlapping) using exact **SantaLucia (1998)** unified nearest-neighbor $\Delta H^\circ / \Delta S^\circ$ and **Owczarzy et al. (2008)** $\text{Mg}^{2+}$ / dNTP / $\text{Na}^+$ salt-corrected $T_m$, scoring GC%, 3' GC clamp, homopolymers, hairpins, self- & cross-dimer $\Delta G_{37}$, and optional background 3'-12mer mispriming.
- **`mc_codon_optimize`**: Optimize protein or DNA CDS sequences for `E_coli_K12`, `HEK293_Human`, `CHO_Cricetulus`, or `S_cerevisiae` maximizing CAI while preserving 100% identical translation, smoothing 30-bp sliding-window GC, relaxing 5' codons 2–8 GC, and removing forbidden restriction sites (`BsaI`, `BsmBI`, `BbsI`, `EcoRI`, `BamHI`, `HindIII`, `NdeI`, `XhoI`), homopolymers, and cryptic Shine-Dalgarno motifs (`AGGAGG` in *E. coli*). Exports FASTA, annotated GenBank `.gb`, TSV audit, and GC/CAI profile plot.
- **`mc_assemble_construct`**: Virtually assemble ordered fragments and optional vector backbones via **GoldenGate** (`BsaI`, `BsmBI`, `BbsI`, `SapI` with overhang fidelity & retained-site checks), **Gibson** (15–60 bp terminal overlap detection & $T_m$), or **RestrictionLigation** (35+ Type II enzymes with compatible cohesive-end recognition). Exports assembled FASTA, annotated GenBank `.gb`, junction audit TSV, and a 2-panel construct map + virtual 1% agarose gel.
- **`mc_sanger_verify`**: Verify cloned plasmids/amplicons from binary **ABIF `.ab1`**, `.fastq`, or `.fasta` traces using a pure-Python `.ab1` parser, Mott quality trimming, strand auto-orientation with circular origin wrap-around alignment, SNV/indel/frameshift calling, and **secondary fluorescence peak deconvolution** $I_2 / (I_1 + I_2)$ for detecting mixed colonies, heterozygotes, or base editing.
