SerpApi provides real-time, structured search engine results across Google Search, Google Scholar, Google News, Google Patents, and other engines, returning ranked links, snippets, citations, and knowledge-graph fields as JSON.

### Capabilities

- Submit keyword and operator queries across web, academic (Google Scholar), news, patent, and image search engines.
- Configure geographic location, language, pagination, and date filters to run reproducible search queries.
- Retrieve structured titles, URLs, snippets, publication metadata, citation counts, knowledge panels, and related questions.
- Paginate through multi-page search rankings for systematic topic or competitive monitoring.

### Use Cases

- Query Google Scholar and Google Patents to cross-check academic citations, preprints, author profiles, and patent filings alongside biomedical databases.
- Locate official websites, documentation pages, conference dates, and funding announcements from institutions and consortia.
- Track public coverage, software releases, or clinical announcements around a target, therapeutic modality, or benchmark dataset.
- Gather dated, link-backed web references for grant background sections, landscape reviews, and technical reports.

### Usage Notes

- Requires a SerpApi API key configured in the connector header settings.
- SerpApi bills per search credit according to your subscription tier; estimate query volume before running paginated or multi-engine batches.
- Homepage: [SerpApi MCP Integration](https://serpapi.com/integrations/mcp). Search rankings vary by region and time; always verify claims against the linked primary source.
