SerpApi 是搜索引擎结果 API，把 Google、Google Scholar 等引擎的搜索结果转换为结构化数据，便于程序读取、筛选和分析。

### 能做什么

- 向多个搜索引擎提交关键词查询，获取网页、新闻、图片等类型的结果。
- 设置地区、语言和设备等参数，观察不同环境下搜索结果的差异。
- 以结构化字段返回标题、链接、摘要、排名和结果元数据，便于后续处理。
- 使用分页参数获取更多结果，支持持续跟踪某个主题的搜索表现。
- 在学术检索中获取 Google Scholar 结果，辅助查找论文、引用和版本信息。
- 读取结果中的相关问题、知识面板等补充信息，为背景调研提供线索。

### 科研中的用法

- 调查研究主题在公开网络中的传播情况，补充文献数据库之外的资料。
- 检索学术会议、实验室、资助机构和数据库的官方页面，核对最新信息。
- 跟踪某篇论文或某位作者的引用与讨论，发现相关工作和合作线索。
- 为科普写作、基金申请背景调研和竞争格局分析收集公开网络证据。

### 使用说明

- 需要 SerpApi API key，并在连接器中配置后使用。
- SerpApi 按搜索次数计费，免费额度和套餐以官网为准；批量查询前应评估调用成本。
- 服务主页：[SerpApi](https://serpapi.com/integrations/mcp)。搜索结果受引擎排名和地区影响，引用时请回到原始网页核实。
