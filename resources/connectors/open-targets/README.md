Open Targets Platform 是 EMBL-EBI 等机构合作维护的靶点发现平台，整合遗传关联、表达、通路、文献和药物证据，帮助研究者评估靶点与疾病之间的关系。

### 能做什么

- 按基因或蛋白名称检索靶点，查看靶点基本信息、功能注释和已知药物。
- 按疾病名称或本体标识符检索疾病，并浏览与该疾病相关的候选靶点。
- 查看靶点—疾病关联的证据类型和评分，区分遗传、表达、通路和文献等来源。
- 获取已知药物、临床候选和适应症信息，辅助药物重定位研究。
- 比较多个靶点的证据构成，快速识别值得进一步验证的方向。

### 科研中的用法

- 在课题立项时筛选具有人类遗传学支持的靶点，优先安排功能实验。
- 为已有药物寻找新的适应症线索，结合疾病关联和已知药物信息形成假设。
- 在论文讨论中核对靶点—疾病证据来源，避免只依据单一数据集下结论。
- 为多组学分析得到的候选基因补充外部证据，缩小验证范围。

### 使用说明

- 无需登录，也无需 API key，连接后即可检索公开数据。
- 关联评分和证据会随数据版本更新，正式引用前请记录访问日期和平台版本。
- 服务主页：[Open Targets Platform](https://github.com/opentargets/platform-mcp)。数据许可、引用方式和免责声明以 Open Targets 官网为准。
