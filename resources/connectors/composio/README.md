Composio Connect 是面向 AI 智能体的工具集成层，用一个 MCP 入口连接 Gmail、Slack、GitHub、Notion、Google Drive、Linear、HubSpot 等 1000+ 款常用应用。

### 能做什么

- 在统一入口中搜索可用的应用与动作，找到完成当前任务所需的工具。
- 按需授权各个应用账号，让智能体读取数据或代为执行操作。
- 组合多个应用完成跨应用流程，例如读取邮件、写入表格并发送通知。
- 查看和管理已连接的应用与权限，控制哪些账号可以被调用。
- 通过连接器把日常工具接入科研工作流，减少在多个界面之间复制粘贴。

### 科研中的用法

- 把文献提醒、邮件和 Slack 消息串起来，及时跟进新论文与课题组通知。
- 将实验记录或分析结果同步到 Notion、Google Drive 等协作空间。
- 用 GitHub 和 Linear 管理分析代码、问题清单和论文修订任务。
- 把表单收集的数据整理到表格，再通知相关成员进行核对。

### 使用说明

- 首次连接需要通过 OAuth 登录 Composio 并授权，使用某个应用时再按提示完成该应用的授权。
- 免费 Hobby 计划每月提供 100,000 次工具调用，无需信用卡；可用应用、动作和额度以 Composio 官网为准。
- 服务主页：[Composio Connect](https://docs.composio.dev/docs/composio-connect)。调用第三方应用时，请同时遵守对应应用的服务条款和权限设置。
