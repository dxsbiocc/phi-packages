cBioPortal 是癌症基因组学数据探索平台，整合 TCGA 等公开癌症研究数据，提供研究、样本、突变和临床数据，供队列分析与假设生成使用。

### 能做什么

- 检索公开癌症研究，查看癌种、样本量、参考基因组和关联文献等基本信息。
- 浏览某一研究中的样本和患者，了解样本类型、患者编号和临床属性。
- 按基因查询突变信息，结合研究背景比较不同队列的突变谱。
- 获取基因的基本注释，并把研究、样本和分子数据对应起来。
- 通过对话快速定位研究编号和字段，减少在网页界面中反复筛选的操作。

### 科研中的用法

- 调查某基因在特定癌种中的突变频率，为实验设计或靶点选择提供线索。
- 比较不同研究队列的样本构成和临床特征，评估数据是否适合合并分析。
- 查找与候选靶点相关的突变和临床信息，形成后续验证的假设。
- 在论文或基金申请中核对公开队列的基本信息和引用来源。

### 使用说明

- 首次连接需要通过 OAuth 登录并授权；连接器只访问公开研究数据，不替代受控数据申请流程。
- 数据来自公开研究，具体研究范围、更新时间和使用限制以 cBioPortal 官网为准。
- 服务主页：[cBioPortal](https://docs.cbioportal.org/ai-integrations/mcp/)。引用数据时请同时核对原始研究和 cBioPortal 的引用说明。
