# NSFC 国家自然科学基金分支（青年 C 类 / 面上 / 重点）

Load this reference ONLY for China NSFC proposals.

## 1. 项目类型与双轨矩阵

| 维度 | 青年科学基金（C 类） | 面上项目 | 重点项目 |
| --- | --- | --- | --- |
| **研究内容体量** | **2–3 个聚焦子课题**（求深忌贪大） | **3–4 个递进子课题**（完整闭环） | **3–4 个大模块 + 协同验证** |
| **前期数据要求** | 切入点苗头（1–2 组核心图） | 扎实直接前期数据（2–4 组图） | 系统积累 + 平台/队列先发优势 |
| **代表作上限** | `<= 5` 篇（突出独立衔接） | `<= 5` 篇（突出连续深耕） | `<= 5` 篇（突出高影响引领） |

- **机制探索型（湿实验 / 临床 / 生命医学）**：`临床/表型痛点 -> 前期队列/组学发现 -> 分子假说`；闭环包含 `队列关联 + 正反向功能干预/Rescue 回补 + 上下游机制 + 干预评估`。关键科学问题聚焦“调控节点/时空特异性/因果阈值”。
- **方法与算法构建型（生信 / AI / 工程 / 交叉）**：`真实计算瓶颈 -> 现有方法数学失效根源 -> 原型发现 -> 新范式`；闭环包含 `统计/数学建模 + 鲁棒性/可解释性 + 仿真/消融/外部多中心 SOTA 基准 + 真实科学问题验证`。关键科学问题聚焦“可识别性、跨分布泛化、噪声与生物学解耦”，忌写成“调包/工程开发”。

## 2. 科学问题属性（2024+ 现行 2 选 1 + 精准理由）

自 2024 年起（延续至 2025/2026），青年 C 类、面上、重点项目已将旧版四类属性合并为 **2 类研究属性**：
- **自由探索类基础研究**：以好奇心、原创思想或国际前沿关键科学问题驱动，强调新机理、新方法或新范式突破，不强制绑定即时工程/产业转化。
- **目标导向类基础研究**：以明确国家重大需求、临床诊疗瓶颈或行业共性“卡脖子”难题倒逼，须清晰落回底层基础科学问题而非纯工程开发。

## 3. 中英文摘要硬规范与实测微示例

- **中文摘要**：系统硬限 `<= 400` 字符（含标点），目标 **350–385 字**，务必用 Python `len()` 实测。
- **英文摘要**：`<= 4000` 字符 + 5 个中英关键词。
- **350 字中文摘要范例**（痛点 -> 前期 -> 方案 -> 意义）：
  > 微卫星稳定型结直肠癌对免疫检查点抑制剂响应率不足30%，髓系细胞介导的免疫排斥是主要耐药瓶颈，但其空间维持机制尚不明确。申请人在前期单细胞与空间转录组分析中发现，耐药肿瘤侵袭前沿显著富集一类高表达*SPP1*的巨噬细胞亚群（`n = 32`例），且其丰度与基质纤维化及CD8+ T细胞排斥高度正相关，提示该亚群可能通过分泌SPP1激活成纤维细胞重塑基质屏障进而诱导耐药。为验证上述假说，本项目拟：（1）在多中心回顾性队列中明确该空间生态位与免疫治疗预后的关联；（2）利用条件敲除小鼠及类器官共培养体系，通过正反向干预阐明SPP1-CD44轴调控基质纤维化与T细胞排斥的因果机制；（3）评估靶向阻断该通路联合抗PD-1治疗的增敏效应。本研究有望阐明髓系-基质互作介导免疫耐药的新机制，为克服耐药提供可干预靶点。
