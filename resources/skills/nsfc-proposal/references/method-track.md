# NSFC 方法与算法构建型（生信 / AI / 工程 / 交叉）参考模板

Load this reference ONLY for methodology, bioinformatics, AI, or engineering-driven NSFC proposals.

## 1. 标准四段式逻辑闭环

1. **立项依据**：真实生物/临床/工程场景的计算瓶颈 -> 现有 SOTA 方法的**数学/理论失效根源**（非简单罗列工具名）-> 前期原型在真实数据上的探索性发现 -> 新建模范式与核心思想。
2. **研究内容（建模-理论-评测-应用闭环）**：
   - 内容 1：统计/数学建模与核心算法设计（明确先验假设、目标函数、可识别性或复杂度保证）；
   - 内容 2：鲁棒性、可解释性与大规模扩展优化（噪声/稀疏/强批次效应/跨中心域偏移处理）；
   - 内容 3：系统化基准评测与开源工具实现（仿真基准 + 消融实验 Ablation + 跨中心外部真实数据集对比 SOTA）；
   - 内容 4：面向真实科学问题的新发现与湿实验/临床佐证（证明方法不仅刷榜，还能产生可验证的新知识）。
3. **关键科学问题**：聚焦**可识别性（identifiability）、跨分布泛化边界、噪声/稀疏耦合解耦、可解释因果表征**，而非“如何训练大模型/如何写软件界面”。

## 2. 关键科学问题与创新点微示例

- **弱写法（纯工程任务）**：
  > 关键科学问题 1：如何基于 Transformer 架构训练多模态空间转录组融合模型并开发在线分析平台。
- **强写法（底层方法学科学问题）**：
  > 关键科学问题 1：在多中心空间转录组存在强批次偏移、低分子捕获率与细胞类型混杂的条件下，如何建立可识别的跨样本空间微环境表征模型，实现真实生物学空间域与技术伪影的数学解耦？

## 3. 方法轨高频扣分红线

- **“调包/套壳”嫌疑**：简单拼接现有 Transformer / GNN / Diffusion 模块，未说明针对领域数据结构（如零膨胀、成分约束、空间自相关）的本质建模创新。
- **缺少外部独立评测与消融实验**：仅在单一内部数据集交叉验证，未评估防泄漏与跨中心泛化。
- **重算法轻科学问题**：脱离开具体生物学/临床瓶颈纯谈指标提升，导致“需求牵引”或“交叉融通”属性论证空洞。
