# NSFC 机制探索型（湿实验 / 临床 / 生命医学）参考模板

Load this reference ONLY for mechanism-driven biomedical / clinical NSFC proposals.

## 1. 标准四段式逻辑闭环

1. **立项依据**：临床/表型痛点 -> 领域前沿与未解机制矛盾 -> **前期队列/组学/预实验证据**自然引出核心分子假说 -> 科学意义。
2. **研究内容（递进闭环）**：
   - 内容 1：临床/队列相关性与时空定位验证（明确表达谱与预后/表型关联）；
   - 内容 2：体内外正反向功能验证（敲降/敲除 + 过表达/回补 Rescue，确立因果必要性）；
   - 内容 3：上下游分子机制解析（互作蛋白、转录/表观/代谢调控节点与关键结构域）；
   - 内容 4（面上/重点）：靶向干预或转化可行性评估（小分子/抗体/类器官/PDX 模型）。
3. **关键科学问题**：聚焦“关键调控节点、时空特异性或因果转换阈值”，**严禁写成实验步骤**（如“如何构建敲除小鼠”）。

## 2. 400 字中文摘要微示例（实测 350 字含标点）

> 微卫星稳定型结直肠癌对免疫检查点抑制剂响应率不足30%，髓系细胞介导的免疫排斥是主要耐药瓶颈，但其空间维持机制尚不明确。申请人在前期单细胞与空间转录组分析中发现，耐药肿瘤侵袭前沿显著富集一类高表达*SPP1*的巨噬细胞亚群（`n = 32`例），且其丰度与基质纤维化及CD8+ T细胞排斥高度正相关，提示该亚群可能通过分泌SPP1激活成纤维细胞重塑基质屏障进而诱导耐药。为验证上述假说，本项目拟：（1）在多中心回顾性队列中明确该空间生态位与免疫治疗预后的关联；（2）利用条件敲除小鼠及类器官共培养体系，通过正反向干预阐明SPP1-CD44轴调控基质纤维化与T细胞排斥的因果机制；（3）评估靶向阻断该通路联合抗PD-1治疗的增敏效应。本研究有望阐明髓系-基质互作介导免疫耐药的新机制，为克服耐药提供可干预靶点。

## 3. 机制轨高频扣分红线

- **只有相关性没有正反向因果设计**（缺少 Rescue 回补实验）。
- **前期数据过多导致“项目已做完”错觉**（前期应支撑假说合理性，切忌写“已完全证实”）。
- **组学堆砌**（单细胞 + 空间 + 蛋白 + 代谢全上，但没有一个可证伪的核心分子假说）。
